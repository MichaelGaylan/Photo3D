16-bit keeps smooth slopes for CNC finishing passes. Use 8-bit for laser software that only reads normal images. STL is for CAM software (Fusion, Carveco, Vectric) and 3D printers.

Test card

Before a real piece, run the test card on scrap of the same material. It has ten depth steps, a smooth ramp, fine rings and thin lines, so you can see how deep each gray carves and how much detail your machine holds. It uses the size and export above.

    About

    Photo3D turns a photo into a 3D relief for laser engravers, CNC routers and 3D printers.

    Privacy. Your photos never leave this device. The app goes online only to download the depth model and 3D viewer the first time, and to send a report when you tap Send.
